# 🌱 FarmMitra

> AI-powered agricultural companion for Indian farmers.

FarmMitra is an AI-based agricultural assistant designed to help
farmers make better farming decisions using text, voice, and image inputs.

The goal of FarmMitra is to provide personalized assistance for
crop selection, crop health, weather, irrigation, farming practices,
and agricultural markets.

---

## 🚜 Features

- 🌾 Crop recommendations
- 🌦️ Weather information
- 💧 Irrigation guidance
- 📸 Crop health analysis
- 💊 Crop care suggestions
- 💰 Market price information
- 🗣️ Multilingual interaction
- 🎤 Voice-based interaction
- 📷 Image-based crop analysis
- 🤖 AI-powered farming assistant

---

## 🌍 Supported Languages

FarmMitra currently supports the following languages

- English
- Tamil
- Telugu
- Kannada
- Hindi
- Malayalam
